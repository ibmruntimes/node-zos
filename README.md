# IBM® Open Enterprise SDK for Node.js

The IBM Open Enterprise SDK for Node.js is a z/OS® port based on the open source community Node.js

For more information, see the [IBM documentation website](https://www.ibm.com/docs/en/sdk-nodejs-zos).

This GitHub repository is used for questions and comments about IBM Open Enterprise SDK for Node.js. However, please note that GitHub support for Open Enterprise SDK for Node.js is on a best-effort basis.
